## 1. Rules the UI must follow

1. The UI states a number, date, sample size or percentage **only** if it comes from a `facts.json` entry (rule 3).
2. `confidence: "verified"` → shown normally, with the source on hover/expand.
3. `confidence: "must-verify"` → shown **only** with the amber badge *"Figure under verification"*, or hidden. Facts whose `source` is `[instructor to add verified source]` (F-PK-FAITH) are **never** shown.
4. `confidence: "disputed"` → shown only with the badge *"Sources conflict"* and the caveat text (F-AIN).
5. `replication` drives the replication badge: robust / mixed / failed / contested / n/a.
6. Helplines (F-H1–F-H6) always carry *"Hours may vary — verify before calling"* and the verified-on date. They are not upgraded to `verified` until confirmed on each organisation's own site.
7. Anything invented by ZEHN (simulated participants, effect sizes not in this file) is labelled **"Simulated data"**.

## 4. Verification method and limits

- **Standard.** A fact is `verified` when A1 found the primary source (journal record, publisher/DOI page, author-hosted copy of the paper, official organisation page) **or** at least two independent reliable sources agreeing on the value. Study-guide sites, flashcards and blogs count as corroboration only, never alone.
- **Tooling on 2026-11-14.** Only a web *search* tool was usable. Direct fetching was blocked by the session network policy for every host tried (`ipip.ori.org`, `pubmed.ncbi.nlm.nih.gov`; curl returned proxy 403). So verification relied on search-result excerpts of primary records (PubMed/PMC entries, APA/APS/Springer/Science pages, university repositories, W3C pages), not on reading full papers. Where only a citation was confirmed, the fact's value is limited to what the snippets supported, and the rest went into the caveat or a separate `must-verify` fact (e.g. F-SM71 vs F-SM71-SLOPE, F-DRM vs F-DRM-RATE, F-BP vs F-BP-RATES, F-BYS vs F-BYS-MID).
- **Seed rows** (F-APA … F-PHQ) were verified by the orchestrator's earlier research. A1 re-checked them where search allowed (OSC, Hagger, Le Texier, Simons & Chabris, Loftus & Palmer, Festinger & Carlsmith, Bridges, APA 3.0). HEC, OpenStax, BPS, Cowan, IPIP and PHQ could not be re-confirmed this pass, so their earlier `verified` status was **retained, not re-earned**. Re-open the HEC PDF and OpenStax page before release.
