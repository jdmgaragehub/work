# Presenter Guide — demo scripts

Open `dist/ZEHN_Psychology_Lab_Simulator.html` and set the seed to `demo-2026` in onboarding.

Before you start:
- **Projector:** Settings → Conference mode (large type, high contrast).
- **Older laptop:** set Quality to Medium.

## 7-minute demo

| Time | Do | Say |
|---|---|---|
| 0:00 | Boot screen | "The neuron network fires along the real loading progress. Note the footer: *simulated institution, data stays on this device*." |
| 0:30 | Onboarding → *Enter the campus* | "Students choose difficulty, seed, accessibility options and content-warning preferences in about a minute." |
| 1:00 | Walk the courtyard (WASD), press **2** for Director view | "This is a fictional psychology campus in Hyderabad. It has nine zones, and each one maps to a week of the course." |
| 1:40 | Rail → **Course Map** | "Each panel shows its APA 3.0 outcome, BPS domain and HEC 2025 course tag. Sixteen weeks are mapped to panels, 3D mechanics, missions, quizzes and tour beats." |
| 2:20 | Press **3** → run **Stroop** | "Consent comes first: purpose, duration, the right to withdraw, data stays local. These are real timed trials. Onset is aligned to the display frame and timing quality is reported." |
| 3:30 | Results → **Statistics Workbench** | "Try-first mode: students compute *t* themselves before the answer appears. The stats are unit-tested against SciPy." |
| 4:20 | Rail → **Ethics Board** | "Students judge proposals using APA Code 8.02, 8.07 and 8.08 and the Belmont principles." |
| 5:00 | Press **4** → meet a simulated client | "This is a fictional client with a FACS face and branching dialogue. Replies are scored on micro-skills (OARS, Rogers), and a supervision report follows." |
| 6:00 | **Replication & Open Science** panel | "Every finding carries a replication badge. Ego depletion shows *failed*; the Stanford Prison Experiment shows *contested*." |
| 6:40 | Press **T** → ask RAAHI "what is d prime" | "RAAHI is an offline AI tutor, not a therapist. It has a crisis detector, and an LLM can be switched on as an option." |

## 15-minute demo

Run the 7-minute script, then add:
1. **A Participant's Journey (J)**, 2 min: consent signature, practice, blocks, debrief, withdrawal option, then your row joining the anonymised dataset and a certificate.
2. **Experimental Lab Wing**, 2 min: look through the Ames-room peephole, then walk out to reveal the trapezoid. Walk around the impossible triangle.
3. **Neuro Atrium (6)**, 1.5 min: brain built with marching cubes, the function selector lights up regions, then fire the neuron bridge and open the Hodgkin–Huxley trace in Biopsychology.
4. **Mohalla (5)**, 1.5 min: bystander model with growing crowd size, labelled *Simulated*. Run Asch, then show the debrief.
5. **APA Report Generator**, 1 min: from a dataset to an APA-7 results paragraph, then print.
6. **Tour (7)**, 1 min: the guided tour, photo mode (P) with depth of field.

## Safety reminders for live demos

- Never type a real personal disclosure into RAAHI as a demo. To show the crisis card, use Settings → Crisis resources.
- State plainly that clients and participants are simulated, and that no one is being diagnosed.
