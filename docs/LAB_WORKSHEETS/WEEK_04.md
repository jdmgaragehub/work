## Procedure in the game

1. Press **6** for Neuro Explorer and walk the **neuron bridge** in the Neuro Atrium.
2. Open **Biopsychology** (`bio`) and start the neuron simulator.
3. Set injected current to 0 and increase it in equal steps. At each step record whether a spike occurs and the spikes per second.
4. Find the threshold current (the lowest step that produces a spike).
5. Enter the **synapse chamber** and block reuptake. Describe what happens to transmitter in the cleft.
