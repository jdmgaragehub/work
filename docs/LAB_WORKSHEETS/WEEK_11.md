## Procedure in the game

1. Enter the **Child Development Suite** and stand behind the one-way mirror. Open **Development** (`development`).
2. Read the coding scheme for simulated separation and reunion episodes (e.g., seeks contact / avoids / resists / mixed).
3. Code 20 simulated episodes. A classmate (or the built-in second coder) codes the same episodes independently.
4. Run **Piaget conservation** (`conservation`) and code each simulated child as conserver / non-conserver.
5. Run **false-belief** (`false_belief`) with simulated children of two age groups and record pass/fail.
